# Decision Log — PRD

## Session: 2026-06-20 — PRD Creation

### Decisions Made

1. **Data persistence (MVP):** Local storage auto-save + `.tomeforge` file export/import for backup. No backend, no user accounts.
2. **Target edition:** D&D 5e (2014) only for MVP. 2024/5.5e edition support is future scope.
3. **Card layout & visual design:** Deferred to `bmad-ux` phase — PRD focuses on requirements, not pixel-level layout.
4. **Public sharing:** Free tier feature (organic marketing). Served via URL encoding or lightweight serverless — open question for implementation.
5. **Monetization model:** Freemium subscription ($3-5/month or $30-50/year) with generous free tier covering core creation, printing, artwork, themes, and sharing.
6. **Premium scope:** Expanded content types (capacities, items, monsters, NPCs), premium art/themes, advanced org, high-res exports, cloud accounts, ad-free.
7. **Export format:** `.tomeforge` (matches product name).
8. **Artwork integration:** MVP feature (free tier). May become partially premium later if needed.
